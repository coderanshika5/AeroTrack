AeroTrack ✈️
Real-Time Aircraft Tracking & Aviation Analytics Platform

A full-stack aviation tracking application that visualizes aircraft telemetry on an interactive map, provides aircraft information, and supports aviation analytics.

Tech Stack: React.js, Node.js, Express.js, PostgreSQL, Prisma, Redis, Leaflet, Docker.

Key Features
- Interactive aircraft tracking map
- OpenSky Network API integration
- Aircraft search and telemetry details
- Historical aircraft observations
- Aviation analytics dashboard
- Redis caching and PostgreSQL persistence
- Demo mode for offline testing
